# Le programme du CERTE

Animation en motion design qui présente le programme de recherche du CERTE (Centre d’expertise et de recherche pour la transformation de l’éducation), d’après la version 3 du programme (4 mai 2026).

La page tient en un seul fichier, `index.html` : polices, logo et animation sont inclus, sans dépendance extérieure.
